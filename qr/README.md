# QR codes — Afaqus

Tous pointent vers `https://afaqus.com` (correction d'erreur niveau H).
Ne fonctionnent qu'une fois le domaine `afaqus.com` en ligne.

| Fichier | Usage |
|---|---|
| `afaqus-qr.png` | Noir sur blanc — le plus fiable (carte de visite, flyer, écran). |
| `afaqus-qr.svg` | Vectoriel — impression grand format sans perte. |
| `afaqus-qr-indigo.png` | Couleur de la marque (indigo). |
| `afaqus-qr-logo.png` | Avec le logo Afaqus au centre. |
| `afaqus-carte-qr.png` | Carte « Scannez pour découvrir », prête à imprimer (85 × 55 mm, 300 dpi). |

Règles d'impression : taille ≥ 2 cm, garder la marge claire autour, fond clair / code foncé,
et imprimer une épreuve d'essai à scanner avant tout tirage.
